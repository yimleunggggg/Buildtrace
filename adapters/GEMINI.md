# BuildTrace project memory

For meaningful project work, read `docs/buildtrace/SKILL.md`, restore relevant context, and update `docs/buildtrace/BUILDTRACE.md` after a meaningful completed change or important decision. Ordinary natural language is enough.

For an existing project, use `.buildtrace/recovery/latest.json` to continue auditing safe accessible Gemini sessions or exports, Git history, project artifacts, compacted context, forks, and subagents. Preserve source boundaries and report anything unavailable.

Before editing existing project memory, run `buildtrace snapshot --target .`; afterwards run `buildtrace verify-history --target .`. Add dated corrections rather than overwriting prior quotes or reasoning.

Never mix another project's records into this project. Markdown is the only editable truth; Viewer and exports are derivatives.
